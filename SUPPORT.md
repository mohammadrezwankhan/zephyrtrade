# Support

Use README for the local demo and PROJECT_ANALYSIS.md for the source map. Check QUALITY_REPORT.md for known platform limitations before reporting a failure.

File a [bug](https://github.com/mohammadrezwankhan/zephyrtrade/issues/new/choose) with OS/runtime version, commit, exact command, expected behavior and redacted logs using fictional data. Use a feature request to explain the workflow and constraints rather than attaching a patch disguised as a bug. Security issues follow SECURITY.md. No external support chat or live-service hotline is operated by this repository.
