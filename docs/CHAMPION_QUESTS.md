# Useful contribution quests for ZephyrTrade

These are contribution proposals, not rewards for stars. Check existing issues before starting.

| Task | Scope | Acceptance evidence |
|---|---|---|
| Trace a first-run journey | Follow `ZephyrTrade-Champion.html` from a clean browser profile | Document each step and actual result; identify ambiguity without adding live data |
| Native persistence check | One saved fictional record, reload, then explicit clear | Browser/version and assertions show persistence or an honest limitation |
| Keyboard review | Primary navigation and one dialog at 390px | Focus order, Escape/return focus and accessible names recorded |
| Bilingual terminology review | One actual screen of ZephyrTrade | Paired strings and explanation reviewed by a fluent reader; no invented official terms |
| Explain a domain invariant | One function from the source map | Small synthetic example and regression assertion linked to the original contract |

Use `quest:starter`, `quest:docs`, `quest:builder` or `quest:visualization` to describe work when labels exist. Acknowledgements belong in release notes after a useful contribution is accepted. No payment, guaranteed recognition, reciprocal starring or engagement requirement is offered.
