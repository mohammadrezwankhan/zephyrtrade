# Troubleshooting

Use the source revision and actual command when reporting a problem. A historical green workflow is not a result for a changed checkout. Preserve the first failure before changing the environment; the observed fixes below changed isolated dependencies or invocation only.

| Symptom | Evidence-based interpretation | Next action |
| --- | --- | --- |
| Pytest exits before collecting tests with `CallSpec2` / AnyIO deprecation | The 2026-11-19 worker loaded an unrelated host plugin under pytest 9.2 and `-W error` | Create a clean environment; if testing the source without optional plugins, explicitly use `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`. Record the initial failure and plugin policy. The isolated run passed 255 tests plus 54 subtests. |
| ESLint reports unresolved Playwright types and many downstream unsafe-value errors | Root `npm ci` alone does not install the nested audit project; the first local lint attempt failed this way | Run `npm ci --prefix tests/browser/audit --ignore-scripts --no-audit --no-fund`, then rerun lint. The second observation passed; do not erase the first. | Chromium exits with `socket() failed: Operation not permitted` / ptrace error | This worker could not launch a browser; failure occurred before page initialization | Use a capable approved runner or the existing browser workflow. Do not infer page correctness from Node tests or regenerate screenshots as if captured. |
| `zephyr-phase2` cannot find processed splits | Full raw/processed training tables are generated outputs and are not all checked in | Use a new-directory `zephyr-run` or the bounded smoke script; preserve retained result CSVs.
