# Parameters, symbols and units

This ledger keeps native names and units. The wind-offer engine uses MW, MWh, hours and DKK; the separate teaching companion uses basis points and USD notional. No currency conversion or common calibration is implemented. The [equations](EQUATIONS_AND_DERIVATIONS.md) explain the signs and objectives.

### Feature names retain their source meaning

The 15 inputs are `actual_power_lag_24h_mw`, `weekly_power_q05_mw`, `weekly_power_q50_mw`, `weekly_power_q95_mw`, `wind_speed_100m_ms`, `wind_gust_100m_ms`, `temperature_2m_c`, `surface_pressure_hpa`, `relative_humidity_pct`, `wind_direction_sin`, `wind_direction_cos`, `hour_sin`, `hour_cos`, `day_of_year_sin`, `day_of_year_cos`. The last six are dimensionless; the four power-history features are MW, wind/gust m/s, temperature °C, pressure hPa and humidity percent. Calendar features use local time and a 365.25-day period. All features are subsequently scaled using training statistics. Complete hourly history is required before the market eligibility filter. [src/zephyrtrade/preprocessing.py:20–73](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/preprocessing.py#L20-L73) [src/zephyrtrade/preprocessing.py:120–248](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/preprocessing.py#L120-L248)

## Separate basis-point teaching model

The page config uses base spread 30 bps, fees 10 bps, slippage 5 bps and USD 10,000 notional. Slider limits are respectively 0–100, 0–50, 0–30 bps and USD 1,000–100,000. The generic runtime fallback has different defaults (35/15/8/10,000), so page defaults must be read from lesson configuration. The teaching spread is `base + 12 sin(2πt/12) + 5 sin(2πt/5)` bps; P&L is `notional × (spread − fees − slippage) / 10000` USD. Time spans 0–24 illustrative hours. No portfolio execution, wind forecast, exchange order, risk budget or currency converter connects this model to the MW/MWh engine. [docs/index.html:160–348](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/docs/index.html#L160-L348)

## Parameter provenance and change discipline

The current settings are software defaults or synthetic assumptions, not field-calibrated uncertainty ranges. Changing them is a new experiment requiring an explicit configuration, dependency versions, input identities, fresh result paths and appropriate tests. This documentation change preserves all numerical settings and original result files. Proposed calibration and sensitivity work is tracked in the [roadmap](../../ROADMAP.md).
