## Optimization and economic interpretation

The native offer model assumes one production variable per interval, fixed known settlement prices, bounded production, and `down <= day-ahead <= up` with a positive up/down spread. It omits transaction fees, collateral, liquidity, bids across coupled intervals, ramping, availability obligations, credit exposure and the actual current settlement design. The scenario sandbox allows negative prices within its ordering, while the retained training/backtest data excludes them. One capability does not restore the excluded observations. Source: [src/zephyrtrade/optimize.py:20–168](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/optimize.py#L20-L168).

Probability scenarios are supplied assumptions, not a fitted risk model. The residual method reuses a validation-error sample with equal weights. Direct classification probabilities are learned estimates, not demonstrated calibration. The deterministic oracle knows output before offering. No code path submits an order or connects to a broker. Low-level functions have narrower checks than the UI/API: `realized_market_revenue` checks arithmetic alignment, while `expected_scenario_revenue` has no capacity parameter. The direct LP probability-mass mismatch is recorded as `ZT-N01`; callers should use the validated boundary or exact normalized inputs pending a separately reviewed source fix. Sources: [src/zephyrtrade/optimize.py:171–255](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/optimize.py#L171-L255), [src/zephyrtrade/direct.py:88–135](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/direct.py#L88-L135), [src/zephyrtrade/app.py:47–84](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/app.py#L47-L84).

The perfect-foresight denominator is a useful oracle under the maintained model, not an external measured ceiling on a real market. A nonpositive denominator makes capture undefined. Different offers can have equal objective value; parity must not require identical offers in flat regions. The Phase 3 comparator is specifically the locally weighted indirect strategy, even if another Phase 2 method ranks higher in a different generated experiment. Sources: [src/zephyrtrade/evaluate.py:72–114](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/evaluate.py#L72-L114), [src/zephyrtrade/phase3.py:283–332](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/src/zephyrtrade/phase3.py#L283-L332), [scripts/verify_engines.py:109–169](https://github.com/mohammadrezwankhan/zephyrtrade/blob/29abf5d8bd6f05b1f0c027d8753f4837840215dc/scripts/verify_engines.py#L109-L169).
