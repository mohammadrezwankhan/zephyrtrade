# ZephyrTrade: voiceover draft

Research application that generates synthetic wind/weather/price tables, compares wind-forecast and direct-offer strategies, backtests revenue and explores hypothetical offers without placing trades. The example runs locally. Start from the README, open a supplied record, and inspect what is known, what is synthetic, and what stays on the device. The source and tests let you inspect the rule behind the interface. This is a demonstration under documented limits. If this workflow is useful, try one reproducible contribution from the project quest list.
