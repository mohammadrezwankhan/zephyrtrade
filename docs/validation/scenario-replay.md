# Fictional scenario replay

The committed [version-1 scenario](../../tests/fixtures/fictional-scenario-v1.json) uses 30 MW capacity, a one-hour interval, 420/610/310 DKK/MWh day-ahead/up/down prices and equally weighted production scenarios of 3, 7 and 11 MW. It is synthetic: no market data or trades are involved. Its schema is the one already exported and imported by Strategy lab.

From an installed checkout with Node available, run:

```sh
python scripts/verify_engines.py --manifest tests/fixtures/fictional-scenario-v1.json
```

On 9 November 2026, Python/SciPy and the browser JavaScript module run under Node both returned a 7 MW offer and 2,540 DKK expected interval revenue. Their objective difference was 0 DKK, within the 0.000001 DKK tolerance. The verifier checks the recorded revenue, quantile and offer; an alternative offer is allowed only if it attains the same optimal objective. The original `python scripts/verify_engines.py` command still compares 120 seeded cases without a manifest.

For the browser half, run `node scripts/preview-demo.mjs` and open `http://127.0.0.1:4173/`. In a fresh browser workspace, select **Strategy lab**, choose **Import JSON**, and select the committed scenario file. The form changes from its default scenarios `2, 5, 9, 13, 18, 24, 28` MW to `3, 7, 11` MW and recalculates the result. On Windows at 1440 × 900, Playwright 1.64.1 with Firefox 157.0 and WebKit 27.2 each displayed **7.00 MW** and **2,540.00 DKK**, with no uncaught page errors or horizontal overflow. The preview HTML came from source commit `4d7abd4` and the verifier was exercised from this change.

After reload, the imported draft returned to the defaults and the displayed offer to 9.00 MW. Import alone does not save a case; the existing **Save scenario** action stores a copy in that browser's local storage, and export provides a JSON backup. Firefox logged no console errors. WebKit logged a CSP inline-style refusal and an optional `/api/health` 404 on each load; the [earlier investigation](strategy-lab-cross-browser-partial.md) records the minimal native-select reproduction and its limits. These observations are specific to the tested flow, not general compatibility certification.

The comparison generated by the verifier compares the scenario objective in Python and JavaScript. The dashboard's precomputed strategy-comparison page is a separate historical synthetic dataset; importing a scenario does not rewrite it. A later [cross-browser check](replay-comparison-cross-browser.md#manifest-driven-offer-comparison) covers the separate manifest-driven offer comparison in Strategy lab.
